# 🤖🔫 AI Target Shooter Game

A cool **Python shooting game built with Pygame** where intelligent AI enemies track and chase the player. Shoot enemies, survive as long as possible, and achieve the highest score!

---

## 🎮 Features

* 🔫 Player shooting system
* 🤖 AI enemies that track the player
* 🎯 Bullet and enemy collision detection
* ❤️ Player health system
* 📊 Live score system
* 📈 Increasing difficulty
* 👾 Random enemy spawning
* 💥 Enemy-player collision
* 🔄 Restart game feature
* 🧠 Basic AI tracking behavior

## 🧠 AI System

The enemies use a simple AI tracking system.

The AI constantly checks the player's position:

* If the player moves left, enemies move toward the left.
* If the player moves right, enemies move toward the right.
* Enemies continue moving downward toward the player.
* As the score increases, enemies become faster and the game becomes more difficult.

This creates a simple **AI-powered enemy tracking system**.
